# Privacy Policy

**Effective date:** August 6, 2026

ChatGPT Anthropic Typography does not collect, transmit, sell, or share personal
information, browsing history, chat content, authentication information, or
analytics.

The extension stores only four user preferences with Chrome's built-in sync
storage: the selected typography mode, whether the optional warm color palette
is enabled, whether Claude-style thinking words are enabled, and whether the
optional Claude-style thinking animation is enabled. These settings are used
solely to apply the user's chosen appearance on `chatgpt.com`,
`chat.openai.com`, and `gemini.google.com`.

The extension makes no network requests and contains no remote code. It does not
read or retain message content. Text-node observation is performed locally and
temporarily only to customize a live thinking-status label when the user has
enabled that option.

Questions and support requests may be submitted through the public GitHub
repository: https://github.com/ensomnia16/chatgpt-anthropic-theme
